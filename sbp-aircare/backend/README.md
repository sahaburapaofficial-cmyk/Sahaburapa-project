# ระบบรับคำขอจากเว็บไซต์ (Google Apps Script + Google Sheet) — Rev.10

> ★ตอนนี้เว็บใช้ **FormSubmit** (ส่งเป็นอีเมลถึง Sahaburapa.official@gmail.com) ตามที่เจ้าของเลือก — คู่มือนี้ใช้เมื่อต้องการย้ายไปเก็บใน Google Sheet: ทำตามขั้นด้านล่าง แล้วแทนค่า `ENDPOINT` ใน `assets/submit.js` ด้วย URL `/exec`

ใช้รับ 3 อย่างจากหน้าเว็บ: **ใบเสนอราคา** (ตะกร้า) · **ติดต่อ** (ฟอร์ม "ส่งคำขอ") · **ความเห็น Beta** แต่ละคำขอได้ 1 แถวใน Google Sheet และอีเมลแจ้งทีม 1 ฉบับ ไม่มีค่าใช้จ่าย

ถ้ายังไม่ตั้ง (`ENDPOINT` ใน `assets/submit.js` ว่าง) เว็บยังทำงานได้ตามปกติ ลูกค้าได้กล่องสรุปให้คัดลอกส่งทาง LINE / อีเมล / โทร เหมือนเดิม

## ตั้งค่า (ประมาณ 10 นาที ทำครั้งเดียว ด้วยบัญชี Google ของบริษัท)

1. เข้า Google Drive ด้วยบัญชีบริษัท (แนะนำ Sahaburapa.official@gmail.com) → สร้าง Google Sheet ใหม่ ชื่อ **SBP AirCare – คำขอจากเว็บ**
2. ใน Sheet: เมนู **ส่วนขยาย → Apps Script** → ลบโค้ดเดิม → วางโค้ดทั้งหมดจาก `apps-script/Code.gs` → แก้ `NOTIFY_TO` เป็นอีเมลทีมขาย (หลายอีเมลคั่นด้วย `,`) → บันทึก
3. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน (บัญชีบริษัท)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด Deploy → อนุญาตสิทธิ์ (Sheet + ส่งอีเมล) → คัดลอก **URL เว็บแอป** (ลงท้าย `/exec`)
4. ส่ง URL ให้ทีมพัฒนา หรือแก้เองที่ `assets/submit.js` บรรทัด `export const ENDPOINT = '…/exec';` แล้ว commit → เว็บบน GitHub Pages build ใหม่อัตโนมัติ
5. ทดสอบ: เปิดเว็บ → ส่งฟอร์มติดต่อ 1 ครั้ง → ต้องเห็น "ส่งถึงทีมแล้ว" + แถวใหม่ในแท็บ **ติดต่อ** + อีเมลแจ้ง

แก้โค้ดสคริปต์ภายหลัง: Deploy → **จัดการการทำให้ใช้งานได้** → แก้ไข → เวอร์ชันใหม่ (URL เดิมใช้ต่อได้)

## ใน Sheet

- แท็บแยกตามชนิด: `ใบเสนอราคา` · `ติดต่อ` · `ความเห็น` (สร้างให้อัตโนมัติเมื่อมีคำขอแรก)
- คอลัมน์ `สถานะ` เริ่มเป็น "ใหม่" — ทีมขายเปลี่ยนเป็น "ติดต่อแล้ว / ออกใบเสนอราคา / ปิดงาน" ได้เอง
- ★Rev.15 **ตารางคิว** — สร้างแท็บ `คิว` เอง คอลัมน์ `วันที่ | เช้า | บ่าย` (วันที่เป็นวันที่ของ Sheet หรือข้อความ `2026-10-05`) พิมพ์ `เต็ม` ในช่องที่ไม่รับงานแล้ว · ช่องว่าง = ว่าง · เว็บอ่านล่วงหน้า 21 วัน (`?q=slots`) แล้วบอกลูกค้าว่าช่วงนั้นเต็มและเสนอวันว่างใกล้สุด — เปิดใช้โดยใส่ URL เดียวกับ ENDPOINT ใน `assets/queue.js` → `QUEUE_URL` (ว่าง = เว็บบอกว่า "ทีมยืนยันคิว" ไม่แสดงว่าว่างเอง)
- ★Rev.15 **ตรวจสถานะคำขอ** (`?q=status&ref=…&tel=4 ตัวท้าย`) คืนค่าเฉพาะคอลัมน์ `สถานะ` ของแถวนั้น เมื่อเบอร์ 4 ตัวท้ายตรงเท่านั้น (ไม่คืนชื่อ เบอร์ หรือยอดเงิน)
- ยอดเงินเป็น **ยอดประมาณการจากหน้าเว็บ** ทีมขายยืนยันราคาในใบเสนอราคาอย่างเป็นทางการทุกครั้ง
